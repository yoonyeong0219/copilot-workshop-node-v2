# 요구사항 — 견적 비교 출력

## 배경

상담 중에 고객이 두 가지 구성을 놓고 고민하는 경우가 많습니다. 지금은 견적서를 하나씩 출력해
금액을 직접 빼 봐야 합니다. 두 견적의 합계와 차액을 한 번에 보여 주는 출력이 필요합니다.

## 요청 내용

`src/format.js` 에 견적 두 개를 비교하는 함수를 추가해 주십시오.

- 함수 이름은 `formatComparison(a, b)` 입니다. `a`, `b` 는 `calculateQuote` 가 돌려주는 견적 결과입니다.
- 결과는 세 줄짜리 문자열입니다.

```
A 합계 41,669,149원
B 합계 48,120,350원
차액 6,451,201원
```

- 첫 줄은 `a` 의 합계, 둘째 줄은 `b` 의 합계입니다.
- 셋째 줄의 차액은 `b` 합계에서 `a` 합계를 뺀 값입니다. `b` 가 더 싸면 음수로 표시합니다.
- 금액 표기는 기존 `formatKRW` 를 사용합니다.

## 테스트

- `test/format.test.js` 에 `formatComparison` 테스트를 추가해 주십시오. 기존 테스트의 스타일을 따릅니다.
- `b` 가 더 비싼 경우와 더 싼 경우를 모두 확인합니다.
- `npm test` 가 모두 통과해야 합니다.
